**💰 Finance Data Analysis | Excel Dashboard**

**📊 Project Overview**

This project is a Finance Domain Data Analysis project developed using Microsoft Excel.

The objective is to analyze financial/loan-related data, track key performance indicators, and build an interactive Excel dashboard that provides a clear overview of loan portfolio performance and customer/application trends.

The project follows an end-to-end data analytics workflow, from data preparation and KPI development to dashboard design and interactive reporting.

**🎯 Business Objectives**

The analysis focuses on answering key business questions such as:

How many loan applications have been received?

What is the total funded loan amount?

What is the total amount received?

How is the loan portfolio performing?

What is the distribution of loan applications by employment length, month, state and purpose?

**📈 Key Performance Indicators**

The dashboard tracks important financial and loan-related KPIs, including:

**KPI	Description**

📋 Total Loan Applications -	Total number of loan applications
💰 Funded Amount	- Total amount funded through approved loans
💵 Amount Received	- Total amount received from borrowers
📊 Average Interest Rate

The interactive Excel dashboard includes:

Loan status analysis

Charts for financial performance

Interactive slicers

Dynamic filtering

Dashboard navigation buttons

Clean and user-friendly layout

These features allow users to interact with the data and analyze different aspects of the loan portfolio.

**🔍 Analysis Performed**

Loan Performance

Analyzed the overall loan portfolio to understand:
Total applications

Funded loan amounts

Amount received

Average interest rate

Loan application performance

Loan Status Analysis
Examined different loan statuses to understand the composition of the portfolio and identify trends in loan applications.

Time-Based Analysis
Analyzed loan applications over time to identify changes in application volume and financial activity.

Interactive Analysis
Used Excel slicers and dashboard controls to allow users to dynamically filter and explore the underlying data.

**💡 Business Insights**

**🚀 Project Outcome**

The project transformed raw financial data into an interactive Excel dashboard that provides a consolidated view of loan applications, funding, repayments, loan status, and performance trends.

It demonstrates how Excel can be used to perform an end-to-end data analysis workflow and communicate financial insights through interactive visualizations.
